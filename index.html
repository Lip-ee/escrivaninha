Escrivaninha

O livro fica num repositório privado seu no GitHub. Esta página não guarda nada: ela só lê e salva lá, com um token que você cria uma vez.

  1. Abra github.com/settings/personal-access-tokens/new.
  2. Token name: Escrivaninha. Expiration: a que preferir.
  3. Repository access: Only select repositories, e escolha o repositório do livro.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, copie e cole abaixo.

O token fica salvo só neste navegador. Em computador compartilhado, use Ajustes → Esquecer este computador quando terminar.
